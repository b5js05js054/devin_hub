# 中继账号资产归属

[English](guide.md) | 中文

## 变更

中继授权记录以后端地址和认证账号会话隔离。退出或切换账号后不能访问原账号的令牌、余额、套餐、商城结果和用量。仅绑定设备的历史授权记录原样保留，绝不自动分配给当前账号。

中继要求签名中的账号 ID 与钱包码相符，且包含设备、授权作用域和有效期。后端保留激活卡设备限制，同账号的多个设备共享账号钱包。归属未知的历史卡余额和卡密不自动合并或认领。

## 迁移

备份后台数据库和请求日志，协调部署后台、中继和客户端，并保持授权密钥一致、配置中继后台 API 地址。重新登录以恢复服务端账号钱包。仅设备身份的旧令牌必须更新；管理员须核实历史账号和付款凭证后才能人工核账。解绑设备保留账号归属；注销账号停用资产并保留身份 ID。

客户端凭据处理见[授权包](../../../../packages/credentials/relay-license/README.zh.md)。
